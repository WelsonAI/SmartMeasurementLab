# Smart Measurement Lab

An interactive visual measurement tool for Malaysian primary pupils from Year 1 to Year 6.

## Learning modes

- Measure and compare length with blocks and a virtual ruler
- Explore mass with an interactive balance scale
- Read and compare liquid volume with measuring containers
- Convert length, mass, and liquid-volume units with a visual unit bridge
- Create custom teacher questions for the current activity

The tool supports Bahasa Melayu, Chinese, and English. It uses the same child-friendly visual system as the other Smart Math tools and works on desktop, tablet, and mobile.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
