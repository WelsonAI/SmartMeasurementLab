# Smart Measurement Lab

An interactive visual measurement tool for Malaysian primary pupils from Year 1 to Year 6.

## Learning modes

- Measure and compare length with blocks and a virtual ruler
- Explore mass with an interactive balance scale
- Read and compare liquid volume with measuring containers
- Convert length, mass, and liquid-volume units with a visual unit bridge
- Create custom teacher questions for the current activity

The tool supports Bahasa Melayu, Chinese, and English. It uses the same child-friendly visual system as the other Smart Math tools and works on desktop, tablet, and mobile.

## Textbook-aligned progression

- Year 1 uses non-standard units such as blocks, balance units, and cups.
- Year 2 reads whole centimetres and standard `g`, `kg`, `mL`, and `L` units.
- Year 3 works with `m` and `cm` and whole-unit conversions; it does not introduce millimetres on the ruler.
- Year 4 measures in whole millimetres and introduces `mm`/`cm` and `m`/`km` relationships.
- Year 5 reads every millimetre as one tenth of a centimetre and uses decimal or fractional unit relationships.
- Year 6 applies the established units and decimal precision without inventing a finer ruler scale.

Teacher-created questions use the same grade-specific units, ranges, and smallest scale divisions.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.
